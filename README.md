# Домашнее задание к блоку «Жизненный цикл и работа с HTTP» — Задача «Анонимный чат»

Приложение представляет собой анонимный чат в реальном времени, разработанный на React 19 и TypeScript 5. Проект реализует периодическое получение данных с сервера (Polling) и сохранение сессии пользователя между вкладками браузера.

## ⚙️ Реализованные требования и технические характеристики

Проект полностью выполняет условия технического задания с применением следующих подходов:

1. **Идентификация пользователя (`userId`):** Уникальный идентификатор сессии генерируется при первом входе и сохраняется в `localStorage` строго под ключом `userId`. Это обеспечивает сохранение идентичности при перезагрузке страницы или при открытии чата в соседних вкладках.
2. **Периодическое получение сообщений (Polling):** В хуке `useEffect` настроен интервал `setInterval`, который каждые 2 секунды отправляет GET-запрос по адресу `http://localhost:7070/messages?from={lastMessageId}`. Идентификатор последнего сообщения отслеживается через `useRef` для корректной фильтрации на бэкенде.
3. **Безопасное обновление состояния:** Для предотвращения гонки запросов при медленном соединении используется флаг `isFetchingRef`. При получении новых данных массив фильтруется на стороне клиента с помощью `Set` для исключения дублирования элементов по их `id`.
4. **Валидация и защита формы (UX):** Поле ввода и кнопка отправки программно блокируются (`disabled`) во время выполнения POST-запроса, что исключает отправку повторных дубликатов сообщений до завершения операции.
5. **Визуальное разделение и раскрашивание:** Сообщения текущего пользователя выравниваются вправо и имеют белый фон. Сообщения других участников выравниваются влево и динамически получают уникальный пастельный оттенок, вычисляемый на основе хэш-функции от их `userId` с фиксированными параметрами HSL (насыщенность 45%, яркость 88%) для сохранения читаемости текста.
6. **Автопрокрутка:** Использование хука `useEffect` с отслеживанием массива сообщений автоматически смещает скролл к контейнеру `chatEndRef` при поступлении нового контента.

## 🛠️ Технологический стек

* **Фронтенд:** React 19 (Функциональные компоненты, Хуки `useState`, `useEffect`, `useRef`)
* **Язык:** TypeScript 5 (Строгая типизация входящих данных и синтетических событий)
* **Сборщик:** Vite 8
* **CI/CD:** GitHub Actions (автоматическая сборка монорепозитория из подкаталога `frontend` на ветку `gh-pages`)

## 🔧 Инструкция по установке и запуску

Для полноценной работы приложения требуется одновременный запуск сервера и клиента.

### 1. Запуск сервера (Backend)

```bash
cd backend
npm install
npm start
```

### 2. Запуск клиента (Frontend)

Откройте второй терминал и выполните сборку зависимостей:

```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```

Приложение будет доступно локально по адресу `http://localhost:5173`.

### 3. Production сборка

```bash
cd frontend
npm run build
```
